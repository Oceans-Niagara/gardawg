What’s inside

      

        

          

            
Code guardrails

            
Deterministic tree-sitter rules for Python, Rust, TypeScript, JavaScript, C and C++ (including Arduino .ino): swallowed errors, missing timeouts, stubs, hardcoded secrets, and more. Gate it in CI with SARIF, or call it from your AI tools over MCP.

          

        

        

          

            
LinkGuard link analysis

            
Check payload sizes, send rates, and framing overhead against real physical-layer limits: LoRa, BLE, Wi-Fi, LEO satellite, UART. Try it in your browser with the LinkGuard sandbox, or run gardawg budget locally.

          

        

        

          

            
Chaos & resilience

            
Seeded, reproducible TCP, UDP, and HTTP impairment proxies show how your code behaves on bad links. Pro adds automated API fault injection with gardawg resilience.

          

        

      

    


    

      
Install & Run Locally

      

        Download a prebuilt binary from GitHub Releases (no Rust toolchain required). Headless builds are best for CI and servers; -gui builds add the desktop GUI.
      

      
# Prebuilt binaries (Windows / macOS arm64 & x64 / Linux):
# https://github.com/oceans-niagara/gardawg/releases/latest
#   Windows: .\gardawg-windows-x86_64.exe init && .\gardawg-windows-x86_64.exe check
#   macOS:   chmod +x ./gardawg-macos-arm64 && ./gardawg-macos-arm64 init && ./gardawg-macos-arm64 check

# Or build from source:
cargo install --git https://github.com/oceans-niagara/gardawg
gardawg init
gardawg check --config gardawg.toml --format sarif
gardawg budget --profile lora-sf12 --bytes 64 --hz 10
gardawg proxy --listen 127.0.0.1:9000 --target 127.0.0.1:9001 --profile ble-1m --seed 42
gardawg mcp
